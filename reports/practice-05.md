# Практика 5. Память и рубежная проверка

Путиенко Алексей Дмитриевич, БФБО-06-24.

Реализована SQLite-память с автоматическим созданием таблицы messages и индексом
по сессии. save использует параметры SQL. window выбирает последние N записей
и возвращает их в хронологическом порядке. Две сессии не смешиваются, clear
удаляет только выбранную. Продукт сохраняется во вспомогательной таблице.
Сигнатуры save и window не изменены. Старые сообщения можно удалить prune(30).

26 быстрых тестов проходят. Проверены окно 4 из 10 сообщений, порядок 6–9,
изоляция, сохранность между Python-процессами, SQL-ввод как строка, очистка,
состояния FSM, клиенты и проверка ссылок. В тесте MCPHistory настоящий
подпроцесс MCP читает настоящую SQLite, модель для этой операции не нужна.
Остальные быстрые тесты ядра используют моки и не выдаются за проверку модели.

Отдельно проверен настоящий трёхрепликовый диалог:
1. Пользователь спрашивает диапазон ПСК, аналитик называет 19,878–39,001%.
2. Пользователь просит объяснить проще, редактор сохраняет диапазон и ссылку.
3. Новый Python-процесс читает SQLite и по уточнению о первом вопросе повторяет
   обе границы. Таким образом, это не только сохранение текста в одном объекте.

Полные ответы, роли и счётчики настоящей модели — live-checks.json.
Две контрольные подмены фрагмента тоже изменили ответ. Вопрос вне проекта
обрабатывается отказом без вызова модели.

Проверено восстановление в чистом клоне с новым виртуальным окружением:
скрипт установки и pip check, импорт трёх PDF по SHA-256, проверка кэша настоящих
моделей, установка Ollama из проверенного официального архива, пересборка индекса
(118 фрагментов, hit-rate@5=100%), настоящий ответ на неоднозначный вопрос и
26 unit-тестов. Кэш весов переиспользован; файлы моделей проверены по хешам.
Веб-чат через AppTest получил настоящий ответ о ПСК и очистил историю с новым
идентификатором сессии. Предыдущие поля ФИО/группы заполнены, пустых эталонов нет.

В MVP один продукт — обычный кредит наличными. П6–П8 остаются будущими заданиями:
триада качества и TCO здесь не объявляются измеренными. Для VK нужен отдельный токен;
подключение к VK не выполнялось. Выбранный рабочий канал — веб-чат и CLI.
