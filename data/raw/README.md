# Документы проекта

Три публичных PDF Т-Банка:

- bank_conditions.pdf — УКБО, редакция 63, 101 страница;
- cash_tariff.pdf — тариф КН 5.0, 1 страница;
- cash_conditions.pdf — публичные условия потребительского кредита, 3 страницы.

Прямые URL, редакции, SHA-256 и выбранные для поиска страницы — в ../../sources.json.
Все PDF сохранены целиком, в Git не входят. Исходные имена могут быть другими:
python scripts/import_sources.py materials сверяет хеши и присваивает имена проекта.
После импорта: python scripts/check_sources.py.

В корпусе рассматривается обычный кредит наличными. Файл УКБО содержит и другие
продукты; для поиска выбраны страницы 40–49, специальные условия других продуктов
помечаются product=other и не передаются модели. Клиентские договоры не добавляются.
