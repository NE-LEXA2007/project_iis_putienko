# Получение зависимостей и материалов

В исходной облачной среде сайты банка и Hugging Face не разрешены сетевым списком.
PDF получены от пользователя и проверены по тексту и SHA-256.
Официальные ссылки сохранены в sources.json; при свободном доступе к интернету
используется scripts/fetch_sources.py, при готовых PDF — scripts/import_sources.py.

Настоящие модели получены из официального каталога Docker Models, доступного
в этой среде как источник пакетов. scripts/fetch_models.py использует обычный OCI
API auth.docker.io и registry-1.docker.io, проверяет digest манифеста и всех файлов.
Прокси и проверка TLS сохраняются. Веса Ollama импортируются из локального GGUF.
Модели закреплены в models/registry-lock.json, временные токены доступа не сохраняются.

Исполняемый файл Ollama 0.40.16 получен с официального GitHub-релиза. Установщик
проверяет опубликованную SHA-256. Скачанные веса, архивы и бинарники не входят в Git.

Для нового запуска нужны процессы: scripts/serve_ollama.sh (отдельный терминал)
и streamlit run app.py. Их состояние не предполагается сохранённым после переноса среды.
