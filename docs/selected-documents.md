# Проверенные материалы

Пользователь передал три PDF с публичных страниц Т-Банка. Файлы прочитаны pypdf,
проверены числовые строки тарифа и пункт 3.11 общих условий кредитования.
URL, SHA-256, редакции и объём записаны в sources.json, образцы текста —
в reports/source-checks.json. Всего 105 страниц; PDF оставлены целиком.

Выбран один продукт — обычный кредит наличными КН 5.0. Страхование, ипотека,
кредиты под залог и кредитные карты не входят в MVP. Для поиска по общему PDF
выбран полный раздел кредитования (страницы 40–49), остальные продукты отделяются
метаданным product и исключаются фильтром оркестратора.
